The most significant layout issue I discovered was that some of the content did not fit properly on smaller screens. The text, images, and navigation links could become crowded, making the website harder to read and navigate.

I used CSS properties such as width, max-width, margin, and padding to organize the content and make the layout cleaner. I also used responsive design techniques, such as media queries, to adjust the layout for different screen sizes.

At narrow viewport widths, the content had less space, so the text and images needed to fit within a smaller area. At wider viewport widths, the website had more room, allowing the content to spread out and become easier to view.

I learned that it is important to test a website at different screen sizes instead of only viewing it on a computer. Testing helped me identify layout problems and understand how CSS can make a website easier to use on both computers and mobile devices.

The next improvement I would make is adding a mobile-friendly navigation menu and making sure all images resize properly on smaller screens. This would help visitors navigate my Japan travel website more easily, regardless of the device they use.
